# 比赛演示脚本（约 8 分钟）

## 开场与环境

1. 展示首页的“模拟环境”标记和模拟数据截止日期，说明样本由 seed `20261122`、normal 情景及固定规则生成，不是真实报价。
2. 确认 `data/competition_demo.sqlite` 已由演示命令生成，报告的 `database_snapshot_sha256` 与测试记录一致。

```powershell
python -m steelchain.demo --db data/competition_demo.sqlite --seed 20261122 --scenario normal
```

报告路径：`reports/P7_DEMO_RESULTS.json`。重复运行时，业务快照哈希、优化交易和预测结果保持一致；调用耗时属于运行元数据，不纳入决策结果比较。

## 场景一：钢厂采购成本优化（约 2 分钟）

在“钢厂采购”工作区点击“运行后端分析”，或提问：

> 我是钢厂，请优化采购成本并列出推荐供方、数量和成本依据。

展示供方、品类、数量、推荐价、运输/加工/质量损耗/资金成本、到厂成本及库存、需求、报价和物流约束。说明建议由 OR-Tools 生成，预览不会自动创建实盘订单。

## 场景二：回收商购销经营（约 2 分钟）

在“回收商经营”工作区提问：

> 我是回收商，请结合可采购需求、现有销售挂牌和运输成本优化经营利润。

展示采购与销售匹配、数量分配、利润代理、成本拆分和多 Agent 执行日志。说明当前利润以可匹配买方价格与供给成本的差额估算，属于模拟决策口径。

## 场景三：自然人销售和额度风控（约 2 分钟）

选择自然人角色并提问：

> 我是自然人，请检查销售资格、推荐销售数量和本年度模拟额度。

展示“仅销售”、库存/需求/报价限制、年度 500 万元上限及额度预留检查。固定测试用例覆盖同一幂等键重复预留不重复占用、超限拒绝及释放后余额恢复。

## 预测与多轮追问（约 2 分钟）

询问：

> 未来 7 天价格、需求和区域供应趋势是什么？

检查每个预测值对应的数据来源、模型或基线版本、目标周期、训练窗口、数据版本、指纹、计算依据及模拟风险提示。继续追问“这个建议基于哪段数据、为什么采用这个方法？”，确认会话角色继承且 Agent 不编造数值。行情历史曲线是模拟历史；挂牌供需快照不是未来预测。

## 收尾

展示 `reports/P7_MODEL_EVALUATION.md`、`reports/P7_ACCEPTANCE.md` 中测试结果和未完成项；明确当前系统是模拟演示，不连接真实市场或下单系统。

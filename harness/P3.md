# P3 实施计划：角色经营决策与交易优化

## 目标
建立共享成本模型及钢厂、回收商、自然人差异化目标；以 OR-Tools 进行品类兼容撮合、供需分配、库存/物流/自然人额度约束下的数量优化；输出利益拆分、推荐价量与约束依据。

## 数据与业务假设
使用 P1 SIMULATED 数据。P2预测模型未通过环境验证，不将其作为输入。单位均为吨、元/吨、元；成本参数支持显式配置。自然人额度按成交金额计算，默认个人年度500万元；额度配置/占用/释放需用唯一交易键与事务语义，不得重复预留。

## 验收计划
单元测试验证成本公式、角色权限与额度幂等；典型场景验证钢厂成本、回收商利润、个人净收益目标与库存/供需/物流/质量边界；报告列出建议依据。OR-Tools不可用则不以启发式冒充求解器验收。

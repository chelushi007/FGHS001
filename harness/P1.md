# P1 实施计划：可复现模拟数据与数据库

## 范围
SQLite 默认可运行（零外部依赖），PostgreSQL DDL 迁移预留 NUMERIC/约束对照；生成 3 年每日行情、20 类品类及业务主体数据，四种市场情景、验证器、统计报告、一键命令和自动化测试。数据均标记 SIMULATED。

## 方案
Python 标准库 sqlite3 + SQL 迁移版本表，避免无网络环境下依赖安装阻塞。命令：`python -m steelchain generate --db data/steelchain.sqlite --seed 20261122 --scenario normal`；支持 `normal|demand_growth|demand_decline|regional_imbalance`。

## 验收
固定 seed 结果可复现；三年每日行情；业务引用完整；自然人只能销售且额度不超 500 万；库存与订单/物流/报价一致；四情景行情变化方向可验证；自动化测试实际运行并记录报告。

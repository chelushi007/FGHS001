# P6 实施计划：自然语言智能决策工作台

## 范围
Next.js/React/TypeScript工作台；总览、智能对话、钢厂采购、回收商经营、自然人销售、行情、供需、撮合、合规导航；ECharts价格/供需图；FastAPI dashboard只读接口与LangGraph真实对话请求；会话多轮关联、错误提示、模拟数据标识及响应式样式。

## 当前限制
P2预测模型尚未验收，P6 UI不得生成预测数值；价格图显示后端行情时间序列，预测状态单独提示。P1品类字典与本次三级分类不同，新增界面字典并明确未映射。

实现完成：各角色及业务导航有独立说明和后端分析入口；三级类目映射通过 API 明确标记精确或待审核，不把未确认候选用于交易约束。`apps/web` 提供 npm 锁文件及 dev/build/lint 命令。

## 验收
FastAPI TestClient验证图表数据契约、CORS、来源标签；全量Python测试；前端 TypeScript 静态检查及 Next 生产构建；桌面/移动浏览器检查和真实服务对话冒烟需在联调环境执行。P6报告记录本次实测与限制。

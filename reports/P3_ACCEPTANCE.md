# P3 角色经营决策与交易优化验收报告

## 交付
- `steelchain/optimization/planner.py`：统一成本、角色目标、供需数量分配和运输距离/容量约束，使用 OR-Tools SCIP/CBC MILP。
- `steelchain/optimization/quota.py`：自然人额度占用、幂等键、成交/释放状态转换。
- `migrations/002_quota_ledger.sql`：额度交易台账及唯一交易键。
- 命令：`python -m steelchain.optimization --role steel_mill|recycler|individual [--party-id ID] [--year YYYY]`。

## 计划目标与计价口径
共同单位成本 = 挂牌采购价 + 区域运输 + 加工 + 质量损耗 + 资金成本。默认参数为运输18元/(吨·区域步长)、加工35元/吨、质量损耗率2%、年资金成本率8%、资金占用30天；均可在 CostConfig 中调整。质量损耗目前是统一配置系数，P1 没有质量指标可用于逐单核算。

钢厂目标：在需求上限内优先满足采购量，并以完全成本最低作为次级目标；回收商目标：使用需求最高价与供给成本差值作为利润代理；自然人目标：按售价扣除运输/加工/质量损耗/资金成本最大化净收益，并受剩余额度限制。每条建议包含数量、推荐价、成本分项、双方金额、约束与优化依据。

## 自动化测试
执行 `python -m unittest discover -s tests -v`：8 项通过，覆盖成本分项、三种角色求解调用、额度预留幂等及释放、非法角色。P1 数据集上的代表性运行：钢厂 OPTIMAL，355 条分配、37,191.53 吨；回收商 OPTIMAL，963 条分配、100,000 吨全局运输容量；个人主体无可用路径，返回 INFEASIBLE（P1 模拟个人库存均已被既有模拟订单预留）。结果全为 SIMULATED，不代表真实建议。

## 尚未满足的验收项/风险
1. 当前是建议规划器，不会将优化方案自动转为订单；额度台账服务是独立原子操作，尚未与优化结果确认形成端到端事务。
2. P1 缺少分配级质量数据和真实运输网络；当前以通用损耗率、区域环形步数和全局容量近似，不足以用于生产交易。
3. 回收商缺少已购原料成本/库存批次成本，现用报价与买方最高价差作为经营利润代理，不能等同实际利润最大化。
4. 浮点成本用于优化系数，交易金额仅为模拟估算；上生产前应采用整数缩放或 Decimal 并由财务口径确认。
5. P2 预测模型阶段此前因 LightGBM 原生 DLL 加载权限问题未通过，因此优化未使用预测输出。

# P7 模型评估报告

## 评估边界

- 来源：固定模拟数据，版本 `P1-sim-v1-seed-20261122-normal`；源表（行情、供给、需求）逻辑指纹 `e13d567e0fb44ce60f6980c4ebf78a5edc6d7408115796959e79784e80f832d6`。
- 覆盖日期：2023-01-01 至 2025-12-31，共 1096 个日点。训练、验证、独立测试按目标日期前向切分，边界见 JSON 报告；验证集仅用于算法/基线选择，测试集只做最终评估。
- 周期：价格、需求、供应各 7/15/30 天。
- 特征：年内日、周内日、月份、归一化时间趋势、1/7/14/30 日滞后、7/30 日历史均值。
- 候选比较：XGBoost、持平基线、7 日均值基线。LightGBM 本轮未进入发布候选：本机 LightGBM DLL 导入返回 `PermissionError (WinError 5)`；其历史 P2 比较记录保留在 [P2 JSON 评估](P2_MODEL_EVALUATION.json)。
- 结果为模拟数据模型预测，不表示真实市场表现。需求/供应目标是从 P1 静态挂牌总量按季节和趋势公式合成的日序列，不是实测历史需求/供应。

## 结论与风险

- 模拟价格序列上的树模型明显输给简单基线；服务因此选择经过验证集选型的持平基线。三个价格周期预测值相同是该基线的确定性结果，不应包装成方向性行情判断。
- 需求/供应 XGBoost 在当前模拟合成目标的独立测试集优于两个基线，但该优势只反映已知的合成季节/趋势过程，不可外推到真实业务。
- 推理会校验训练/推理源表指纹。切换到需求增长、需求下降或区域失衡数据而没有对应模型版本时，返回模型不可用，不沿用正常情景模型。
- 实际推理 API 输出 `data_origin`、模型/基线版本、训练与推理指纹、数据版本、训练窗口、目标日、特征依据和风险提示。
